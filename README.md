# Shaheen Rahman Dibya — Portfolio

Personal engineering portfolio built with HTML, CSS, and JavaScript.

## GitHub Pages

In repository Settings → Pages, select Deploy from a branch, then main and / (root), and Save.

Website: https://shaheendibya.github.io/github-portfolio/

Edit index.html for biography and education, app.js for project details, and style.css for styling. Supporting documents and images are in assets/.
